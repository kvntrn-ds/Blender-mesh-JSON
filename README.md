# Blender-mesh-JSON
A blender script I made to export a selected mesh to a JSON file which then is automatically used to create the mesh. This immediately causes a duplicate of the mesh using the JSON file that was created! 

# Blender → JSON Mesh Exporter 

Select any mesh → run script → get clean JSON + perfect rebuilt copy.

Works on:
- Default primitives
- Imported .fbx / .obj buildings
- High-poly sculpted models
- Runs from Text Editor on Windows/Mac/Linux
